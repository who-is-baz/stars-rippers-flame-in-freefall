# FortiGuard Web Filter classification (optional, recommended by the 2026 Project Submission Guide)

Purpose: reduce the chance that the judges' network blocks a brand-new site. Do it **after** the site has its final URL.
The guide gives only these instructions; the exact form layout may differ, so follow what the form shows.

1. Open the *FortiGuard Web Filter Classification* form linked from the Project Submission Guide
   (spaceappschallenge.org → Resources → Project Submission Guide → "Link to Final Project").
2. **URL:** the final public URL of the site (the one in `docs/submission/final_project_link.md`).
3. **Category:** choose the one that best describes the site. The guide lists as examples: *education*, *personal website
   and blogs*, *reference*, *web-based application*. Our suggestion: **Reference** (a data reference dashboard) or, if the
   form offers it, **Education**. NASA Space Apps does not choose the category for teams.
4. **Company Name:** write `N/A` (as the guide says).
5. Fill the other required fields (name, email, comment). Suggested comment: "Static educational dashboard built for the
   NASA Space Apps Challenge 2026; shows open NASA PSI combustion data (CC0). No login, no ads, no user data collected."
6. Submit the request. The classification is decided by FortiGuard; it is not required for the project submission.
