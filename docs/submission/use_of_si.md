# Use of Super Intelligence (SI)

Yes. We used SI tools heavily, as tools. The project idea and approach (organise the PSI tests by cabin atmosphere and
show what the evidence covers) came from the team's brainstorming and the official challenge objectives. Every
AI-assisted task is recorded in `docs/AI_USAGE_LOG.md` (one entry per task, 14–15 Nov 2026). This text summarises that log.

## Tools
- **Anthropic Claude Code** (models Claude Opus 5.5 and Claude Sonnet 5.5): most of the code, scripts, tests and repository
  documentation.
- **Anthropic claude.ai** (Claude Opus 5.5 and Sonnet 5.5, in a team Project): design guidelines ("skills"), an HTML design
  reference, three design reference images and prompts for team members.
- **Local LLMs through Ollama (optional feature of the product):** the assistant is configured for Llama 3.2 3B (Flash),
  Qwen3 8B (Medium) and Qwen3 14B (Heavy). **Flash (Llama 3.2 3B) and Medium (Qwen3 8B) were run on the demo laptop and benchmarked on 12 questions** (`docs/bench/RESUMEN.md`); **Heavy (Qwen3 14B) was not downloaded and was not evaluated.** Their text is checked by code (numbers must come from the data, forbidden claims are rejected) and often replaced by a fixed template; the log records what failed with the real models. The public site never uses a model.

## Where SI was used
1. **Data pipeline (code by Claude Code, run and checked by the team lead):** finding the PSI download endpoints,
   download and verification scripts (SHA-256), processing scripts, the unified table (403 tests), SQLite database, query
   module and tests. Raw NASA files were never modified.
2. **BASS-II outcomes (AI-extracted data):** BASS-II has no outcome column, only free-text notes. Claude Code wrote
   extraction rules for those notes and refined them in 3 rounds after manual checks; 26 of 129 tests got an outcome,
   ambiguous ones stay empty. These values are labelled in the data (`ai_*` columns, `extracted_by=AI`,
   `outcome_source = ai_extracted`) and in the site ("AI-extracted"). Three of them are flagged `low_confidence` and
   **still await human review**.
3. **Material categories:** proposed by Claude Code; approved by our data lead (Fer) without changes; one value (P14)
   corrected by Fer and marked `fer_corrected`.
4. **Atmosphere scenarios:** the NASA quotes for the lunar habitat and Exploration Atmosphere were read by an AI session
   from NASA technical reports. Three scenario sources are marked "Unverified source" in the site until a team member
   confirms them. The PMMA figure we cite (Link et al., Sci Rep 2018) was checked by Claude against the article, not by a
   team member.
5. **Website (frontend):** UI code, layout, charts, the Custom explorer and English interface text were generated by Claude
   Code from the team's design brief and AI-written design guidelines. No number is written by SI: all figures are read
   from the data files.
6. **API and assistant (backend):** all code by Claude Code: FastAPI endpoints, the closed list of query tools, the
   verification of model text (numbers must come from the data; forbidden claims are rejected) and 129 automated tests.
7. **Documentation and this submission text:** drafted by Claude in English from our logs and data; reviewed by the team
   lead before submission (**MANUAL: confirm**).

## What the team reviewed (and what is still pending)
- Reviewed: data files and processing decisions (team lead), material mapping and the P14 correction (Fer), design
  decisions, dependencies and branches (team lead, in each session).
- Verified by the AI itself with automated tests (Python: 129 passed; website: 70 passed; build; Lighthouse), not yet
  line-by-line by a person: backend code, most frontend code, design skills and prompts. The log marks "human review
  pending" for these items.
- Pending: the 3 `low_confidence` BASS-II outcomes, the 3 unverified atmosphere sources, the API contract sign-off.

## How SI is marked in the project (metadata)
- Commits with AI-generated changes carry `AI-assisted: yes`; `docs/AI_USAGE_LOG.md` lists each task, model and files.
- Data: `ai_*` columns, `extracted_by=AI`, `outcome_source`, `qc_flags`.
- Website: answers written by a local model are labelled "AI-generated text"; answers without a model say "no model".
  The page states "SI (Super Intelligence), i.e. an AI/LLM assistant".
- Images: the site has no AI-generated images (the chamber is an SVG drawing labelled "Illustration. Not a combustion simulation."). Three AI-generated design reference images that were only in the team's design docs were deleted from the repository on 15 Nov 2026 before it was made public. The screenshots in `docs/screenshots/` are captures of the site itself.
- No NASA logos, flags or mission identifiers are used or modified by any generated content.
