# High-Level Summary

An evidence map, not a guess: it shows what NASA's microgravity data can and cannot tell a Moon-base designer. Flame in Freefall Explorer is a public, evidence-first dashboard for NASA microgravity combustion data. It organises 403 ISS tests from NASA PSI (274 FLEX fuel-droplet tests and 129 BASS-II solid-material tests) by cabin atmosphere. Pick an atmosphere, such as Earth/ISS air or the expected Moon-base air, and see which tests are closest to it (ordered by a transparent relevance formula), how they ended, what is covered, and what remains unresolved. For the Moon-base air in the challenge (30% O2 or more, 10.2 psi or less) there are 0 exact tests and 17 near tests: the site states this as its headline, computed from the data, and lists what NASA should test next. An investigations card arranges the investigations named in the challenge text under prevention, detection and suppression, and shows which ones have test-level data here. Every number shows its sample size and source DOI. An optional SI assistant answers only from these data, with citations, and says "No data" when the data cannot answer. It is descriptive: no safety rating, no forecast. It shows mission planners what the evidence covers, and where new tests are needed.
