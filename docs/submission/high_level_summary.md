# High-Level Summary

Flame in Freefall Explorer is a public, evidence-first dashboard for NASA microgravity combustion data. It organises 403 ISS tests from NASA PSI (274 FLEX fuel-droplet tests and 129 BASS-II solid-material tests) by cabin atmosphere: oxygen and pressure. Users pick an atmosphere, such as Earth/ISS air or the expected Moon-base air, and see how many real tests are close to it, how those tests ended, and what is missing. For the Moon-base air in the challenge (30% O2 or more, 10.2 psi or less) there are 0 exact tests and 17 near tests. Every number shows its sample size and source DOI. An optional SI assistant answers only from these data, with citations, and says "No data" when the data cannot answer. This matters because it shows mission planners what the evidence covers, and where new tests are needed, without inventing values.
